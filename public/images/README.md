# ArtUnity Youth Images

Place web-ready images here. Use the naming below so pages auto-pick them up.

Recommended sizes (min):
- Hero/section: 1600×900
- Cards: 1200×675
- Team headshots: 800×800 (square)

## Paths and filenames used by the site

- Homepage mission image
  - `public/images/about/mission.jpg`

- Homepage events (3 placeholders on home)
  - `public/images/events/event-1.jpg`
  - `public/images/events/event-2.jpg`
  - `public/images/events/event-3.jpg`

- About page mission image
  - `public/images/about/mission.jpg` (same as homepage)

- Team headshots (About page)
  - `public/images/team/sarah.jpg`
  - `public/images/team/marcus.jpg`
  - `public/images/team/aisha.jpg`
  - `public/images/team/david.jpg`

- Optional (not yet wired, but available for future use)
  - Backgrounds: `public/images/backgrounds/...`
  - Partners: `public/images/partners/{partner-name}.png`
  - Logos: `public/images/logos/{logo-name}.svg`

Notes:
- Keep file names lowercase, no spaces. Use hyphens.
- Use compressed JPG/WEBP for photos, PNG/SVG for logos/icons.
- After adding images, refresh the page; they’ll be picked up automatically.
